# Playwright + TypeScript — API, Accesibility, Intercept-Network & Visual Testing & other examples

---

## 🚀 Quick start

```bash
git clone {find the url in the github}
cd Playwright-TS-API-Accesibility-Intercept_Network-Visual
npm ci
npx playwright test
```
